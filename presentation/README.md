# Presentation materials

This folder contains the slides from my in-class mini-project presentation.

The in-class presentation covered an earlier version of this project, a volatility-prediction model for the S&P 500. After the presentation, the project was refocused on extreme market events, market behavior and stress testing, which is the version in the written report and notebook. The slides are included as the record of that presentation; where they differ from the report, the report and notebook reflect the final analysis.
