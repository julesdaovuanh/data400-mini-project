# Presentation materials

`Jules_Dao_Vu_Anh_Mini_Project_Presentation.pptx` contains the slides from my in-class mini-project presentation.

The presentation covered an earlier version of this project: whether macroeconomic indicators and the VIX improve five-day volatility forecasts for S&P 500 sectors, with the April 2025 tariff shock as the case study. After the presentation, the project was refocused on extreme market events more broadly: how different types of shocks move the market, how it recovers, and how to stress-test portfolios. That final version is the one in the written report and notebook. The slides are included as the record of the presentation; where they differ, the report and notebook reflect the final analysis.
